# Milan Jewelers

Professional website for **Milan Jewelers** — a fine jewelry boutique located at 901 Atlantic Ave, Ocean City, MD 21842, inside Saltwater Trading Co.

## Features

- Elegant, responsive single-page design
- Luxury boutique color palette with gold accents
- Smooth scroll navigation
- Sections: Home, About, Collections, Services, Gallery, Visit, Contact
- Contact form with confirmation
- Google Maps integration
- Scroll-triggered animations
- Mobile-first responsive layout

## Tech Stack

- **React 19** with Vite
- **Tailwind CSS** for styling
- **Lucide React** for icons
- **Google Fonts** (Cormorant Garamond & Montserrat)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The built site will be in the `dist/` directory.
